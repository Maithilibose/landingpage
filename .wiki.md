# Project Summary

An immersive AI-assisted historical manuscript restoration platform that helps researchers move from damaged physical artifacts to readable text, evidence-supported reconstruction, and historical interpretation. The site presents this workflow as a cinematic, scroll-driven archaeological journey using supplied manuscript videos inside a responsive Three.js environment.

The product emphasizes trustworthy restoration: directly recognized text, AI-assisted reconstruction, confidence indicators, evidence, and explicit unresolved states rather than unsupported guesses.

# Project Module Description

- **Landing experience**: Continuous scroll journey covering discovery, artifact examination, restoration, script identification, analysis, transcription, reconstruction, uncertainty, interpretation, workflow, and access request.
- **3D environment**: React Three Fiber and Three.js provide spatial video planes, camera movement, lighting, transitions, depth, parallax, and archaeological atmosphere.
- **Video media**: Four supplied films are configured centrally, displayed as video textures with poster-frame fallbacks, lazy loading, muted playback, and off-screen pausing.
- **Restoration narrative**: Communicates the progression from original material to enhanced, recognized, reconstructed, and unresolved states.
- **Evidence UI**: Confidence badges, evidence cards, and abstention cards explain certainty and insufficient evidence.
- **Script identification**: Highlights currently supported Odia and Urdu manuscripts while marking Tamil, Malayalam, Bengali, and Sanskrit as coming soon.
- **Research pipeline**: Presents transcription, transliteration, translation, and historical context as the final interpretation workflow.
- **Navigation and layout**: Responsive top navigation, chapter rail, progress indicator, footer, CTA sections, and mobile adaptations.
- **Access request**: Validated form persists submissions in `localStorage` and generates a confirmation reference that survives reloads.
- **Blog**: Prerendered blog index and article pages using Markdown content and blog-specific routes.
- **Accessibility and fallback**: Reduced-motion support, non-WebGL native video fallback, responsive layouts, readable contrast, and mobile-specific complexity reduction.

# File Description Inventory

## Application and pages

- `src/App.tsx`: Root application composition and page routing.
- `src/main.tsx`: React bootstrap.
- `src/pages/Index.tsx`: Full landing-page journey and document-flow sections.
- `src/pages/AuthCallback.tsx`: Authentication completion handling.

- `src/pages/blog/BlogIndexPage.tsx`: Blog listing.
- `src/pages/blog/BlogPostPage.tsx`: Individual blog post page.
- `src/blog-routes.tsx`: Blog route configuration.

## Landing scenes

- `HeroScene.tsx`: Opening proposition and primary CTA.
- `ArtifactScene.tsx`: Archaeological discovery and manuscript artifact.
- `RestorationScene.tsx`: Restoration and enhancement narrative.
- `ScriptScene.tsx`: Script identification and language support.
- `AnalysisScene.tsx`: Layered AI analysis and evidence markers.
- `TranscriptionScene.tsx`: Original manuscript to recognized text.
- `ReconstructionScene.tsx`: Evidence-supported reconstruction states.
- `UncertaintyScene.tsx`: Abstention and unresolved results.
- `InterpretationScene.tsx`: Transcription, transliteration, translation, and context.

- `FinalCtaScene.tsx`: Closing message and access request.
- `SceneLabel.tsx`: Scene titles, labels, and metadata.
- `manuscriptScenes.ts`: Central scene definitions and replaceable video paths.

- `LandingCanvas.tsx`: WebGL scene container and fallback behavior.
- `VideoPlane.tsx`: Video-texture planes, poster fallbacks, lazy loading, and playback control.
- `CameraController.tsx`: Scroll- and pointer-driven camera movement.
- `SceneEnvironment.tsx`: Spatial archaeological environment.
- `Lighting.tsx`: Scene illumination and visual mood.
- `SceneTransition.tsx`: Cinematic scene transitions.
- `textureUtils.ts`: Texture and media preparation helpers.

# Usage

From the frontend directory:

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

The project includes prerendered landing and blog routes in the production output. Replaceable video assets are configured in `src/data/manuscriptScenes.ts`; the corresponding files belong in `public/videos/`.
